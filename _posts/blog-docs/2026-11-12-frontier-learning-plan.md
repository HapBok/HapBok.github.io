## 지금까지의 활동을 돌아보며

악성코드 탐지 AI, 발화보조 서비스, 현업 과제 해결 프로젝트와 여러 공모전·해커톤에 참여했다. 모델과 데이터셋을 만들고, 프로젝트를 고도화하거나 팀장을 맡아 기획·발표에 참여하는 경험을 쌓았다. 올해에는 다섯 차례 CTF·해킹방어대회에도 참가했다.

프로젝트와 수상 경험은 쌓였지만, 보안 문제를 원리부터 분석하고 설명하는 역량은 더 보완하고 싶다. 장기적으로는 공격자 관점에서 시스템의 약점을 이해하고, 분석 결과를 방어 강화로 연결하는 레드팀 전문가를 목표로 하고 있다.

## 부족함을 느꼈던 부분

### CS 기초와 설명하는 힘

취약점 분석 트랙의 최종 면접을 경험하면서 컴퓨터 구조·운영체제·네트워크 등 CS 기초를 더 보완해야겠다고 느꼈다. 공개 자료에서 공격 흐름을 읽고 정리하는 것과, 그 과정의 권한 경계·발생 원인·영향 범위를 직접 설명하는 것은 다르다고 생각했다.

앞으로는 어떤 명령이나 코드로 결과를 얻었는지만 기록하지 않고, 정상 동작과 비교해 왜 그런 결과가 나왔는지도 설명할 수 있도록 공부하고 싶다.

### 학습 범위와 우선순위

여러 분야를 한꺼번에 공부하려고 계획을 세웠지만 일부 목표는 계획대로 마치지 못했다. 관심 있는 주제를 늘리는 것보다 현재 수준에 맞게 우선순위를 정하고, 배운 내용을 실제로 확인하는 방식이 필요했다.

한 주제를 학습한 뒤 작은 실습을 하고, 그 결과를 내 말로 설명한 뒤 다음 주제로 넘어가는 방식으로 바꾸려고 한다.

### CTF 경험과 LLM 활용

CTF·해킹방어대회 다섯 곳에 참가했고 핵테온 세종에서는 본선에 진출했지만, 수상하지는 못했다. 대회에 참가하며 LLM을 사전에 어떻게 설정하는지가 중요하다고 느꼈지만, 아직 CTF·Wargame을 체계적으로 학습한 상태는 아니다.

보안 지식과 문제풀이 경험이 쌓여야 LLM 에이전트에 무엇을 맡길지, 어떤 정보를 제공할지 더 잘 판단할 수 있을 것 같다. LLM 활용 방법과 함께 내가 문제를 이해하고 판단하는 역량도 키우고 싶다.

## 앞으로 어떻게 채울 것인가

FRONTIER 활동에서는 주제 하나를 공부하고, 실습하고, 설명하는 것까지 마친 뒤 다음으로 넘어가려고 한다.

| 보완할 부분 | 할 일 | 확인 방법 |
| --- | --- | --- |
| CS 기초 | 현재 실습에 필요한 컴퓨터 구조·운영체제·네트워크 개념을 하나씩 공부한다. | 용어와 동작을 내 말로 설명하고 작은 실습으로 확인한다. |
| 취약점 분석 | 허가된 환경에서 사례를 분석하며 정상 동작, 권한 경계, 원인, 성립 조건과 패치 차이를 확인한다. | 직접 재현한 결과와 자료에서 읽은 내용을 구분해 기록한다. |
| CTF·Wargame | 현재 수준에 맞는 문제를 풀고 막힌 부분의 기초 개념을 다시 공부한다. | 풀이 원리를 설명하고, 해설을 참고했다면 도움받은 부분도 남긴다. |
| LLM 에이전트 | 문제를 풀 때 사용할 역할·지침·정보를 정리하고, 사용 후 설정을 보완한다. | 도움이 된 부분과 직접 검증해야 했던 부분을 기록한다. |
| 기록과 협업 | 한 주제나 활동을 마칠 때 결과와 막힌 지점을 정리해 공유한다. | 내가 한 일과 팀 전체 결과, 확인한 사실과 남은 의문을 나누어 적는다. |

## 가장 먼저 시작할 일

먼저 참가했던 CTF나 수행한 프로젝트에서 다시 살펴볼 주제 하나를 고르려고 한다. 필요한 기초 개념을 정리하고, 작은 실습으로 확인한 뒤 과정과 결과를 글로 남기는 것부터 시작하겠다.

합동강화훈련과 온라인 미션에서도 이 방식을 이어갈 생각이다. 공부한 개념으로 문제를 이해하고, 확인한 결과를 설명할 수 있는지부터 점검하려고 한다.
