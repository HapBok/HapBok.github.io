# 밝은 HapBok 리디자인 안내

## 2026-11-10 큰 화면 정렬·H 이미지 보완

이전에는 `.reading-layout`의 `justify-content:start` 때문에 2560px급 화면에서도 글과 목차가 왼쪽에 붙었습니다. `_sass/_refinements.scss`에서 이를 `center`로 바꿔 남는 공간을 읽기 영역 양쪽에 나눴습니다. 본문은 최대 820px를 유지하므로 한 줄이 화면 전체로 길어지지 않습니다. 사이드바를 닫으면 더 넓어진 가용 공간을 기준으로 다시 가운데에 놓입니다.

목차가 실제로 오른쪽에 있는 1400px 이상에서만 두 열을 사용하고, 목차가 없으면 한 열로 가운데 정렬합니다. 작은 화면에서는 기존의 본문 위 접이식 목차와 모바일 서랍을 유지합니다.

표지 H는 차가운 금속 조형에서 크림색 직물·청록·보라 옆면의 손그림 질감으로 바꿨습니다. `index.md`에서 새 파일 `assets/images/cover/h-emblem-illustrated.png`를 사용합니다. 두 강아지의 기존 이미지·프레임·반응은 그대로 사용하며, 이전 H 파일과 원본 생성 이미지는 보존했습니다. 생성에 사용한 전체 프롬프트는 `asset-sources.json`의 `coverRefresh`에 있습니다.

이번 보완 검증: 2555px에서 사이드바를 열면 글·목차 묶음 양쪽 여유 공간이 각각 506px, 닫으면 각각 663px로 일치했습니다. 본문 최대 폭은 820px이며, 1440px 오른쪽 목차와 1024px·320px 접이식 목차를 확인했습니다. 가로 넘침은 없었습니다. Jekyll 빌드와 12개 필수 경로·자산 검사, 기존 자동 테스트 4개가 통과했습니다. 화면은 `screenshots/wide-reading-balanced.png`와 `screenshots/cover-illustrated.png`에 있습니다.

예전 `outline`, `file_name`, `directory_label` 값이 남아 있어도 새 화면은 의존하지 않습니다.

## 현재 구성

~~~text
_layouts/       default(공통) → archive(기록) → category(분류)
                default(공통) → post(게시글)
_includes/      상단 메뉴, 주제 메뉴, 홈 소개, 글 목록, 캐릭터
_data/          카테고리 이름·URL·분류 키·캐릭터 연결
_posts/         실제 Markdown 글
categories/     6개 카테고리의 설명·빈 상태 문구
_sass/          tokens / base / shell / home / archive / post / characters / responsive
assets/
  css/          style.scss(위 SCSS를 불러오는 진입점)
  js/modules/   메뉴 / 검색 / 목차 / 본문 도구 / 캐릭터
  images/       실제 사용 중인 캐릭터 PNG
  fonts/        Pretendard 파일과 OFL 라이선스
scripts/        빌드 검사·캐릭터 회귀 테스트·격리 QA 글 생성
docs/           이 안내서·자산 출처·화면 캡처(공개 사이트에서는 제외)
~~~

HTML/Liquid는 화면의 요소와 실제 글을 연결합니다.
SCSS는 그 요소의 위치·색상·크기·간격을 정합니다.
JavaScript는 검색·메뉴·목차·캐릭터의 상태와 반응을 담당합니다.
Markdown은 앞으로 작성할 학습 기록입니다.

## 화면과 동작

- 표지: `/`는 H 조형물·두 아이·입장 버튼만 있는 별도 첫 화면입니다.
- 홈: `/home/`에 소개, 해피·복순이, 실제 최신 글, 6개 주제와 블로그 소개를 배치합니다.
- 기록·카테고리: 접을 수 있는 250px 폴더 메뉴, 검색창 하나, 최신순 목록. 글이 없으면 기존 안내 표시.
- 게시글: 폴더 메뉴와 최대 820px 본문, 우측 목차. 공간이 부족하면 접이식 목차로 전환합니다.
- 소개: 별도 메뉴·화면을 없애고 홈의 `#about`으로 합쳤습니다. 기존 주소는 이 영역으로 이동합니다.
- 검색: 여러 단어는 모두 포함하는 글을 찾습니다. 제목·설명·본문을 검사하며 대소문자를 구분하지 않습니다.
- 검색 오류: 원래 정적 목록을 유지하고 재입력 안내를 표시합니다.
- 이미지: 본문 이미지만 클릭 확대합니다. 메뉴 캐릭터와 홈 이미지는 확대 대상이 아닙니다.
- 코드 복사: 원문을 복사하고 성공·실패를 표시합니다.
- 글 제목·문단은 스크롤 등장 효과로 숨기지 않습니다.

## 표지·사이드바·모션 추가 수정

- 화면 전체의 1220px 고정 폭을 없앴습니다. 2555px 화면에서 좌측 시작 여백은 72px이고, 사이드바를 접으면 본문 영역이 그 자리까지 넓어집니다.
- 글을 읽는 줄까지 끝없이 늘리지는 않습니다. 바깥 화면과 목록은 넓게, 본문은 최대 820px로 유지합니다.
- 카테고리 이름을 누르면 하위 글이 보입니다. 옆의 ‘전체’는 기존 카테고리 URL로 이동합니다.
- 현재 게시글의 폴더는 자동으로 열리고, 해당 글을 표시합니다. 빈 폴더에도 안내 문구가 있습니다.
- 사이드바 버튼은 데스크톱에서는 레이아웃 접기, 모바일에서는 서랍 열기·닫기로 작동합니다.
- 모든 캐릭터 include가 반응 버튼이 됩니다. 마우스 진입·클릭·키보드 선택 시 짧게 반응하며 동작은 중복 대기열에 쌓이지 않습니다.
- 홈·표지는 기존 신체 프레임 인사를 재생합니다. 다른 페이지는 상황별 PNG를 가볍게 움직입니다.
- 입장·기록 버튼에는 눌림·상승·그림자 반응을 적용했습니다. 본문 문장은 움직이지 않습니다.
- 움직임 줄이기 설정에서는 캐릭터·버튼 이동과 H 포인터 모션을 중지합니다.

관련 파일: 표지는 `index.md`·`_layouts/cover.html`·`_sass/_cover.scss`, 홈은 `home.md`, 탐색은 navigation 모듈, 공통 반응은 motion 모듈입니다.

추가 검증: 2555px 전체 폭, 1440px 표지·게시글, 390px 표지와 모바일 폴더, 320px 가로 넘침을 확인했습니다.
자동 회귀 테스트는 4개이며 사이드바·폴더·모바일 상태 분리, hover 중복 방지와 움직임 줄이기를 포함합니다.

## 모션 원칙

홈 두 캐릭터는 각자 10개 프레임을 가진 독립 버튼입니다.
시선·눈 감기·인사 프레임을 전환하며 전체 그림을 회전시키지 않습니다.
자동 인사는 처음 보일 때 한 번, 클릭 인사는 중복 대기열 없이 한 번씩 재생합니다.
화면 밖·비활성 탭에서는 타이머를 취소합니다.
OS의 움직임 줄이기 설정에서는 자동 프레임 전환을 중지하고 정적으로 보여 줍니다.
본문을 읽는 동안 옆에서 캐릭터가 계속 움직이지 않습니다.
