# 밝은 HapBok 리디자인 안내

## 무엇이 달라졌나요?

| 기존 | 변경 후 | 이유 |
| --- | --- | --- |
| VS Code 활동 바·파일 트리·문서 탭 | 작은 상단 메뉴 + 기록 화면의 주제 메뉴 | 파일 관리 화면보다 글을 찾고 읽는 흐름에 집중 |
| 다크 앰버·라임 | 밝은 중성색·진한 본문·절제된 블루 | 긴 한글 문단과 코드의 가독성 확보 |
| 글꼴 이름만 Pretendard로 지정 | 실제 Pretendard Variable WOFF2 자체 제공 | 방문자의 폰트 설치 여부와 무관한 표현 |
| 카테고리마다 목록 HTML 보유 | 공통 archive 레이아웃 | 목록 수정이 모든 분류에 일관되게 반영 |
| outline 값을 h2 순서와 수동 연결 | 본문 h2/h3에서 자동 생성 | 글 작성 시 목차를 이중 관리하지 않음 |
| main.js에 모든 기능 | 기능별 JS 모듈 | 검색·목차·캐릭터를 독립적으로 수정 |
| 테마 의존 | 자체 레이아웃·SCSS | 사용하지 않는 Hacker 테마 스타일 제거 |

기존 글의 Front Matter와 본문, 카테고리 분류 키, 게시글 URL은 유지했습니다.
기존 글의 ‘탐색기·탭’ 설명은 당시 구성에 대한 기록이므로 임의로 다시 쓰지 않았습니다.
예전 `outline`, `file_name`, `directory_label` 값이 남아 있어도 새 화면은 의존하지 않습니다.

## 현재 구성

~~~text
_layouts/       default(공통) → archive(기록) → category(분류)
                default(공통) → post(게시글)
_includes/      상단 메뉴, 주제 메뉴, 홈 소개, 글 목록, 캐릭터
_data/          카테고리 이름·URL·분류 키·캐릭터 연결
_posts/         실제 Markdown 글
categories/     6개 카테고리의 설명·빈 상태 문구
_sass/          tokens / base / shell / home / archive / post / characters / responsive
assets/
  css/          style.scss(위 SCSS를 불러오는 진입점)
  js/modules/   메뉴 / 검색 / 목차 / 본문 도구 / 캐릭터
  images/       실제 사용 중인 캐릭터 PNG
  fonts/        Pretendard 파일과 OFL 라이선스
scripts/        빌드 검사·캐릭터 회귀 테스트·격리 QA 글 생성
docs/           이 안내서·자산 출처·화면 캡처(공개 사이트에서는 제외)
~~~

HTML/Liquid는 화면의 요소와 실제 글을 연결합니다.
SCSS는 그 요소의 위치·색상·크기·간격을 정합니다.
JavaScript는 검색·메뉴·목차·캐릭터의 상태와 반응을 담당합니다.
Markdown은 앞으로 작성할 학습 기록입니다.

## 화면과 동작

- 홈: 소개, 인사하는 해피·복순이, 실제 최신 글, 6개 주제 링크.
- 기록·카테고리: 220px 주제 메뉴, 검색창 하나, 최신순 목록. 글이 없으면 기존 안내 표시.
- 게시글: 최대 740px 본문과 우측 목차. 좁은 화면에서는 접이식 목차.
- 소개: 학습 목적과 두 아이 이름의 유래만 사용.
- 검색: 여러 단어는 모두 포함하는 글을 찾습니다. 제목·설명·본문을 검사하며 대소문자를 구분하지 않습니다.
- 검색 오류: 원래 정적 목록을 유지하고 재입력 안내를 표시합니다.
- 이미지: 본문 이미지만 클릭 확대합니다. 메뉴 캐릭터와 홈 이미지는 확대 대상이 아닙니다.
- 코드 복사: 원문을 복사하고 성공·실패를 표시합니다.
- 글 제목·문단은 스크롤 등장 효과로 숨기지 않습니다.

## 모션 원칙

홈 두 캐릭터는 각자 10개 프레임을 가진 독립 버튼입니다.
시선·눈 감기·인사 프레임을 전환하며 전체 그림을 회전시키지 않습니다.
자동 인사는 처음 보일 때 한 번, 클릭 인사는 중복 대기열 없이 한 번씩 재생합니다.
화면 밖·비활성 탭에서는 타이머를 취소합니다.
OS의 움직임 줄이기 설정에서는 자동 프레임 전환을 중지하고 정적으로 보여 줍니다.
본문을 읽는 동안 옆에서 캐릭터가 계속 움직이지 않습니다.

## 검증 기록

2026-11-10 로컬 검증:

- GitHub Pages 호환 Jekyll 3.10.0 / github-pages 233 컨테이너 빌드 성공.
- 실제 사이트 11개 페이지, 필수 URL 11개, 내부 링크·정적 앵커·CSS 자산·폰트 파일 검사 통과.
- 기존 글 1개가 홈·전체 기록·블로그/기술문서·검색에 반영됨을 확인.
- 실제 브라우저에서 1440·1024·390·320px 배치와 가로 넘침 확인.
- 제목·본문 전용 단어·영문 대소문자·빈 검색어·결과 없음·검색 오류 후 원래 목록 복구 확인.
- 모바일 메뉴·Esc 닫기·포커스 복귀·검색 입력창으로 이동 확인.
- 격리된 QA 글에서 긴 글·h3·중복 한글 제목의 고유 앵커·마지막 절 목차·소제목 없는 짧은 글 확인.
- 코드 복사 성공, 본문 이미지 확대·Esc 닫기·원래 버튼으로 포커스 복귀 확인.
- 별도 실패 서버에서 웹폰트가 없어도 본문이 보이고, atlas 실패 시 정적 캐릭터로 복구됨을 확인.
- Node 회귀 테스트 2개 통과: 연속 클릭·화면 밖·탭 비활성·움직임 줄이기, 코드 원문 보존·클립보드 거부 처리.
- 실제 브라우저의 정상 페이지에서 JavaScript 오류·경고 없음.
- 지정 색상 대비: 본문 13.69:1, 보조 글자 5.89:1, 링크 6.74:1 (배경 #f7f8fa 기준).

‘움직임 줄이기’와 클립보드 거부 분기는 자동 회귀 테스트로 확인했습니다. 브라우저/OS 설정을 임의로 변경하지 않았습니다.
화면 캡처는 이 폴더의 screenshots/에 있습니다. 임시 QA 글은 tmp/에만 있으며 배포하지 않습니다.
